# Product micro-copy

- Start from the screen state and the next action, not a slogan.
- Use all caps for a button or section header and sentence case for body copy.
- Address the person or their named subject when the interface provides it.
- Keep established action verbs consistent across adjacent screens.
- Reassure before asking a question about health, price or eligibility.
- Acknowledge the situation before collecting data in a claims-adjacent flow.
- Remove humour as soon as a sentence carries financial, legal, medical or eligibility weight.
