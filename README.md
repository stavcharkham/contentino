# Contentino

An internal content tool built around a brand profile: a folder of markdown that defines how
a company writes. The engine generates content, scores it against that profile, and feeds
human edits back in so the profile improves with use.

It does two things. Low-stakes content produces and publishes itself with nobody watching.
High-stakes content arrives as a better draft, and a person still owns it.

Approved guidelines do not sit in a settings screen. They graduate into a skill in the
company plugin and a tool in the agent.
