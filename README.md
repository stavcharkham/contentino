# Contentino

An open-source content generation tool built around a brand profile: a folder of markdown
that defines how a company writes. The engine generates content, scores it against that
profile, and feeds human edits back in so the profile improves with use.

> **Status: in development.** This README is written last. See [PRD.md](PRD.md) for what
> it does, [DECISIONS.md](DECISIONS.md) for why it is built this way, and [PLAN.md](PLAN.md)
> for what is left.
